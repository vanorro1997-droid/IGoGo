Поиск по 2ГИС

Поиск мест по Places API 2ГИС и текущая погода по вашему местоположению (WeatherAPI). API-ключи хранятся на сервере и в браузер не передаются.

Ваше местоположение
Координаты определяются автоматически. Можно ввести вручную: долгота, широта.

Поиск выполняется рядом с вашим местоположением. Если геолокация недоступна, введите координаты вручную.
